Battery Health Center

All your laptop battery information in one place, for GNOME: health, cycle count, charge limits, sleep drain, power modes and which apps use the most energy.

Install

These commands add the repository once. After that, apt keeps the app up to date with the rest of your system.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://arios4k.github.io/apt/key.asc | sudo tee /etc/apt/keyrings/battery-health-center.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/battery-health-center.asc] https://arios4k.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/battery-health-center.list
sudo apt update
sudo apt install battery-health-center

Then open Battery Health Center from your applications.

Works on

  • Ubuntu 24.04 and newer, Zorin OS 18, Linux Mint 22, Debian 13 (any 64-bit Intel/AMD system with GTK 4.14 and libadwaita 1.5 or newer)
  • Not on Ubuntu 22.04 or Debian 12: their libadwaita is too old

Remove

sudo apt remove battery-health-center
sudo rm /etc/apt/sources.list.d/battery-health-center.list /etc/apt/keyrings/battery-health-center.asc

Other ways to install

  • Snap Store: sandboxed, so the power-mode and power-saving settings and real app icons are unavailable
  • Source code and build instructions

The apt version is the full one: real app icons, per-app energy use, the complete Power page, and charge limits through the normal password prompt. Don't install it together with the snap.
